# GameShelf / Estantería de Juegos

## 🇪🇸 Español  
*(English version below)*

### 📌 Descripción  
GameShelf es una aplicación Android desarrollada en **Kotlin** cuyo propósito es permitir a coleccionistas y entusiastas consultar información de videojuegos clásicos y gestionar de forma sencilla su colección personal.  
La app utiliza **Firebase Firestore** como base de datos online y **Room** como base de datos local.

### 🚀 Características principales  
- Consulta de videojuegos clásicos por consola  
- Acceso a una gran biblioteca online  
- Gestión de colección personal  
- Base de datos local sincronizada  
- Interfaz simple e intuitiva  

### 📚 Manual de uso  
El manual oficial en PDF incluye guía de instalación, uso, errores conocidos y preguntas frecuentes.  
Puedes encontrarlo en el repositorio en la carpeta **Manual de Uso**.

### 📌 Funcionalidades previstas  
- Búsqueda por título  
- Pantalla ampliada con información detallada  
- Importar juegos a colección personal  
- Mejoras en visualización y elementos multimedia  
- Expansión del catálogo y consolas soportadas

---

## 🇬🇧 English

### 📌 Description  
GameShelf is an Android application developed in **Kotlin**, designed to help collectors and enthusiasts browse information about classic video games and manage their personal collection.  
It uses **Firebase Firestore** as an online database and **Room** for local storage.

### 🚀 Main Features  
- Browse classic games by console  
- Access an online game library  
- Manage your personal game collection  
- Local database with offline support  
- Clean and intuitive interface

### 📚 User Manual  
The official PDF manual includes installation instructions, usage guide, known issues and FAQ.  
It is available in the repository under **Manual de Uso**.

### 📌 Planned Features  
- Title search bar  
- Detailed game information screen  
- Import games into the personal collection  
- Improved UI with cover images  
- Expanded catalog and supported consoles
